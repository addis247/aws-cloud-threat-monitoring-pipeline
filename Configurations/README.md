# Sanitized Configurations

This folder contains sanitized configuration examples used in the AWS Cloud Threat Monitoring and Alerting Pipeline.

## Files

- `guardduty-event-pattern.json`: EventBridge pattern used to select high-severity GuardDuty findings

## Security Notice

Account IDs, email addresses, ARNs, access keys, detector IDs, bucket names, and other account-specific information must not be published.

The configuration examples are provided for portfolio demonstration and should be reviewed before use in another AWS environment.
