## Redaction Requirements

Before publication, remove or obscure:

- AWS account IDs
- Email addresses
- ARNs
- Access keys
- Detector IDs
- Subscription IDs
- Bucket names
- Public IP addresses
- Personal names
- Browser profile information
- Billing information
